Bubble Sort Algorithm

Understand the steps, process, and complexities

🔹 What is Bubble Sort?

Bubble Sort is a simple comparison-based sorting algorithm. It works by repeatedly swapping the adjacent elements if they are in the wrong order.

🔹 Step-by-Step Process

  1. Start from the first element and compare it with the next one.
  2. If the first element is greater than the second, swap them.
  3. Move to the next pair and repeat the process till the last element.
  4. After each pass, the largest element is pushed to the end.
  5. Repeat the above steps for all elements except the sorted ones at the end.

🔹 Example Walkthrough

Example array: [5, 2, 9, 1, 5, 6]

  • Pass 1: [2, 5, 1, 5, 6, 9]
  • Pass 2: [2, 1, 5, 5, 6, 9]
  • Pass 3: [1, 2, 5, 5, 6, 9]
  • Pass 4: [1, 2, 5, 5, 6, 9] (Already sorted)

🔹 Time Complexity

Case Time Complexity
Best Case (Already Sorted) O(n)
Average Case O(n2)
Worst Case (Reversed Order) O(n2)

🔹 Space Complexity

O(1) — Bubble Sort is an in-place sorting algorithm, meaning it doesn't need extra space.
