Breadth-First Search (BFS) Algorithm

Explore graph level by level using a queue

🔹 What is BFS?

Breadth-First Search (BFS) is a graph traversal algorithm that explores all neighbors of a node before moving to the next level of neighbors. It uses a queue to keep track of the nodes to be explored.

🔹 Step-by-Step Process

  1. Start from the root (or any starting node).
  2. Mark the node as visited and enqueue it.
  3. While the queue is not empty:
    1. Dequeue the front node.
    2. Visit and enqueue all unvisited neighbors of the node.

🔹 Example Walkthrough

Graph: { A: [B, C], B: [D, E], C: [F], D: [], E: [], F: [] }, Start: A

  • Queue: [A]
  • Visit A → Enqueue B, C → Queue: [B, C]
  • Visit B → Enqueue D, E → Queue: [C, D, E]
  • Visit C → Enqueue F → Queue: [D, E, F]
  • Visit D → Queue: [E, F]
  • Visit E → Queue: [F]
  • Visit F → Queue: []

🔹 Time Complexity

Graph Type Time Complexity
Using Adjacency List O(V + E)
Using Adjacency Matrix O(V2)

🔹 Space Complexity

O(V) — due to the visited list and the queue.
