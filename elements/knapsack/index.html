0/1 Knapsack Algorithm

Optimize what you pack to maximize value!

🔹 What is the Knapsack Problem?

The 0/1 Knapsack problem is a classic dynamic programming problem where you're given items with specific weights and values. The goal is to choose items to maximize the total value without exceeding the weight limit.

🔹 Step-by-Step Process

  1. Define a DP table with dimensions [items + 1][capacity + 1]
  2. Initialize the table with 0s (base case: no items or zero capacity)
  3. For each item, iterate through capacities and choose to:
    • Exclude the item → carry over previous value
    • Include the item → add value and subtract weight
  4. Update the table using: dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])

🔹 Example

Items: [Weight: 1,2,3] — [Value: 6,10,12], Capacity = 5

Max value = 22 (items 2 and 3)

🔹 Time Complexity

Case Time Complexity
General O(n × W)

🔹 Space Complexity

O(n × W) (can be optimized to O(W) using a 1D array)
