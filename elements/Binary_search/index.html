Binary Search Algorithm

Efficient search in sorted arrays using divide and conquer

🔹 What is Binary Search?

Binary Search is an efficient algorithm for finding an item in a sorted array by repeatedly dividing the search interval in half.

🔹 Step-by-Step Process

  1. Find the middle element of the array.
  2. If the target equals the middle element, return its index.
  3. If the target is less than the middle element, repeat the search on the left half.
  4. If the target is greater, repeat the search on the right half.
  5. Continue this process until the element is found or the interval is empty.

🔹 Example Walkthrough

Sorted array: [1, 3, 5, 7, 9, 11], Target: 7

  • Step 1: Middle = 5 (index 2), 7 > 5 → Search right half
  • Step 2: Middle = 9 (index 4), 7 < 9 → Search left half of right part
  • Step 3: Middle = 7 (index 3), Match found!

🔹 Time Complexity

Case Time Complexity
Best Case (Middle Match) O(1)
Average Case O(log n)
Worst Case O(log n)

🔹 Space Complexity

O(1) for iterative, O(log n) for recursive due to call stack.
