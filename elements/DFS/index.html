Depth-First Search (DFS) Algorithm

Explore graph deeply before backtracking

🔹 What is DFS?

Depth-First Search (DFS) is a graph traversal technique that explores as far as possible along each branch before backtracking. It uses a stack (explicit or recursive call stack).

🔹 Step-by-Step Process

  1. Start from the root (or any starting node).
  2. Mark the node as visited.
  3. Recursively or iteratively visit all unvisited neighbors.
  4. Backtrack when no unvisited neighbors are found.

🔹 Example Walkthrough

Graph: { A: [B, C], B: [D, E], C: [F], D: [], E: [], F: [] }, Start: A

  • Visit A → Stack: [A]
  • Go to B → Stack: [A, B]
  • Go to D → Stack: [A, B, D]
  • D has no unvisited → backtrack to B
  • Go to E → Stack: [A, B, E]
  • Backtrack to A → Go to C → Then F
  • Final Order: A → B → D → E → C → F

🔹 Time Complexity

Graph Type Time Complexity
Using Adjacency List O(V + E)
Using Adjacency Matrix O(V2)

🔹 Space Complexity

O(V) — due to the visited list and the recursion stack.
