Dijkstra's Algorithm

Find the shortest path from a single source to all vertices!

🔹 What is Dijkstra's Algorithm?

Dijkstra's Algorithm is used to find the shortest paths from a single source node to all other nodes in a weighted graph with non-negative edge weights.

🔹 Step-by-Step Process

  1. Initialize the distance to the source as 0 and all others as ∞.
  2. Mark all nodes unvisited. Set the source as the current node.
  3. For the current node, consider all of its unvisited neighbors and calculate tentative distances.
  4. Update the neighbor's distance if the new path is shorter.
  5. Once all neighbors are considered, mark the current node as visited.
  6. Choose the unvisited node with the smallest tentative distance as the new current node.
  7. Repeat until all nodes are visited or destination is reached.

🔹 Example

Graph: A → B (4), A → C (2), B → C (5), B → D (10), C → D (3)

Start: A → Shortest paths: A→C (2), A→B (4), A→D (5)

🔹 Time Complexity

Using Time Complexity
Array O(V²)
Min-Heap (Priority Queue) O((V + E) log V)

🔹 Space Complexity

O(V) for distance storage and O(V + E) for the graph representation.
