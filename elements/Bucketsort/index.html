Bucket Sort Algorithm

When distribution saves the day!

🔹 What is Bucket Sort?

Bucket Sort is a sorting algorithm that distributes elements into several groups called buckets. Each bucket is then sorted individually, either using another sorting algorithm or recursively applying bucket sort.

🔹 Step-by-Step Process

  1. Set up an array of empty buckets.
  2. Scatter: Go over the original array, putting each object in its bucket.
  3. Sort each non-empty bucket individually.
  4. Gather: Visit the buckets in order and put all elements back into the original array.

🔹 Example Walkthrough

Example array: [0.42, 0.32, 0.23, 0.52, 0.25, 0.47, 0.51] (range [0,1])

  • Distribute into buckets based on ranges: (0.2–0.3), (0.3–0.4), (0.4–0.5), (0.5–0.6)
  • Sort individual buckets.
  • Concatenate buckets: [0.23, 0.25, 0.32, 0.42, 0.47, 0.51, 0.52]

🔹 Time Complexity

Case Time Complexity
Best Case (Uniform Distribution) O(n + k)
Average Case O(n + k)
Worst Case O(n2)

🔹 Space Complexity

O(n + k) — for creating the buckets.
